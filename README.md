# NBA Recommendation System

This project delivers an end-to-end NBA roster recommender powered by LightFM collaborative filtering. It includes:

- **Model training pipelines** (`player_cluster.py`, `team_cluster.py`, `rec_sys.py`) to cluster players/teams, construct interaction/data matrices, and train per-era LightFM models.
- **FastAPI backend** (`backend/app.py`) serving recommendations, explanations, cluster summaries, and static assets (player headshots + cluster visuals).
- **Next.js frontend** (`nba-recs-frontend/`) that lets users pick a team/season, view recommendations with explanations/headshots/cluster cards, and browse cluster overviews with PCA plots and population heat bars.


## Getting Started

### 1. Environment

Create and activate a Python environment (conda or venv) and install dependencies:

```bash
pip install -r requirements.txt
```

Ensure Node.js ≥ 18 is available for the Next.js app.


### 2. Data Preparation & Modeling

1. Place raw CSVs inside `data/` (already populated for this repo).
2. Run clustering scripts to generate metadata, cluster visuals, and summary counts:

```bash
python player_cluster.py
python team_cluster.py
```

3. Train LightFM models and persist them via `models_all.joblib`:

```bash
python rec_sys.py
```

Re-run these scripts whenever data changes so the backend serves fresh explanations and cluster visuals.


### 3. Backend (FastAPI)

From the repo root:

```bash
cd backend
uvicorn app:app --reload
```

Endpoints:

- `GET /teams` – team → seasons mapping
- `POST /recommendations` – recommendation request (`{ era, user_id, k }`)
- `GET /cluster-summary/player` / `GET /cluster-summary/team` – cluster counts per era
- Static assets served from `/static/...`


### 4. Frontend (Next.js)

```bash
cd nba-recs-frontend
npm install
npm run dev
```

Set `NEXT_PUBLIC_API_BASE` in `.env.local` if the backend is not on `http://127.0.0.1:8000`.


## Key Features

- **Explainable recommendations**: Each suggested player includes top user features (team traits) and top item features (player traits), user/item biases, and cluster visuals.
- **Season filtering**: Recommendations are limited to the selected season’s player pool.
- **Headshots & cluster cards**: Player cards show Basketball-Reference headshots; cluster cards summarize archetypes with PCA plots and bar charts.
- **Cluster overview tab**: Explore dominant player/team clusters per era, counts, and PCA projections.


## Project Structure

```
backend/              FastAPI app + static assets
data/                 Raw CSV inputs
models_all.joblib     Serialized LightFM models
nba-recs-frontend/    Next.js UI
player_cluster.py     Player clustering & visuals
team_cluster.py       Team clustering & visuals
rec_sys.py            LightFM training pipeline
inference.py          Recommendation + explanation helpers
```


## Notes & Tips

- The recommender relies on Basketball-Reference player IDs (e.g., `wrighde01`). Headshot URLs are constructed to match.
- When adding new cluster labels, ensure `backend/static/cluster/` contains matching `player_<slug>.png` / `team_<slug>.png` so the frontend can display them.
- Large scripts (`player_cluster.py`, `team_cluster.py`, `rec_sys.py`) can take a couple minutes; consider running them in screen/tmux if needed.
